# Securix® · visão do projeto

> **Em uma frase:** uma narrativa visual de cibersegurança empresarial, construída como projeto conceitual de front-end.

[← README](../README.md) · [Requisitos](REQUIREMENTS.md) · [Roadmap](ROADMAP.md)

---

## Objetivo

Criar uma landing page conceitual de portfólio para a Securix®, empresa fictícia de cibersegurança empresarial. A experiência atual percorre seis capítulos com navegação vertical nativa e quatro especialidades apresentadas em sequência.

## Público e mensagem

Público B2B com operações digitais complexas. A página deve comunicar proteção, confiança, precisão e organização. Os textos são em português europeu e não incluem referências geográficas nem provas sociais inventadas.

## Escopo implementado

React, TypeScript estrito, Vite, CSS nativo, Header, seis capítulos, Footer, motion discreto, camadas selecionáveis, especialidades no fluxo vertical, cadeado 3D procedural interativo, fallback em CSS e verificações técnicas.

## Fora do escopo

Backend, formulários de contacto, autenticação, APIs, recolha de dados, modelo 3D externo e publicação.

## Riscos

- O cadeado procedural tem um custo de JavaScript elevado; o módulo 3D é separado do bundle principal e a renderização pausa fora do ecrã.
- Os destinos da navegação devem existir nesta fase para evitar ações vazias.
- Efeitos gráficos não devem impedir a leitura ou o uso com movimento reduzido.
